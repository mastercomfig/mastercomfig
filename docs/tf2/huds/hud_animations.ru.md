# Использование манифеста анимаций HUD

_Оригинал опубликован omnibombulator на huds.tf_

Наличие файла `hudanimations_tf.txt` в пользовательском HUD доставляло немало хлопот с обновлениями TF2. Это основная причина большинства вылетов и багов в игре. Даже обновление, которое почти не меняет элементы HUD, может вызвать проблемы, если файл `hudanimations_tf` устарел.

Но есть способ избежать этой головной боли, позвольте мне провести вас через него.

`hudanimations_manifest.txt`, волшебный файл
Когда вы извлекаете HUD из TF2 с помощью GCFScape или этого [удобного репозитория на GitHub](https://github.com/Hypnootize/TF2-Default-HUD/tree/master/%23TF2%20Files), вы найдёте файл `hudanimations_manifest.txt` в папке `scripts`. Это основной файл, который мы будем использовать, чтобы избежать вылетов, связанных с анимациями HUD, и необходимости постоянно обновлять `hudanimations_tf` после каждого патча.

Файл чрезвычайно прост и содержит не более 6 строк кода:

```json
hudanimations_manifest
{

"file" "scripts/hudanimations.txt"
"file" "scripts/hudanimations_tf.txt"
}
```

`hudanimations_manifest` это файл, который указывает игре, из каких файлов читать анимации. Таким образом, она читает из стандартного файла Source `hudanimations.txt` и файла TF2 `hudanimations_tf.txt`. Но мы можем добавлять в этот список свои файлы.

Для начала зайдите в папку `scripts`, откройте файл `hudanimations_tf.txt` и скопируйте все анимации, которые были изменены в вашем HUD.
Обычно изменяют анимации здоровья (`HudHealthBonusPulse`, `HudHealthBonusPulseLoop`, `HudHealthBonusPulseStop`, `HudHealthDyingPulse`, `HudHealthDyingPulseLoop`, `HudHealthDyingPulseStop`), анимации боеприпасов (`HudLowAmmoPulse`, `HudLowAmmoPulseLoop`, `HudLowAmmoPulseStop`) и анимации медика (`HudMedicCharged`, `HudMedicChargedLoop`, `HudMedicChargedStop`).
Вставьте изменённый код в новый текстовый файл. Для примера сохраните файл как `hudanimations_custom.txt` в папку `scripts`. Теперь у вас есть собственный файл анимаций, отлично!

Следующий шаг удалить (или переименовать, если вы не уверены, что не пропустили какой-то изменённый код) пользовательский файл `hudanimations_tf.txt`. Он нам больше не понадобится — теперь игра сможет читать оригинальный файл из `.vpk`, который входит в состав игры. Это означает, что анимации всегда будут обновляться вместе с игрой!

Теперь вернёмся к файлу `hudanimations_manifest.txt`. Нам нужно добавить туда созданный нами файл `hudanimations_custom.txt`, чтобы игра могла считывать анимации и из него.

Всё просто, добавьте новую строку **выше** строки с `hudanimations_tf.txt` (как показано ниже) и сохраните файл:

```json
hudanimations_manifest
{

"file" "scripts/hudanimations.txt"
"file" "scripts/hudanimations_custom.txt"
"file" "scripts/hudanimations_tf.txt"
}
```

Вы можете добавлять сколько угодно файлов с анимациями, можете хранить анимации здоровья, боеприпасов и медика в отдельных файлах, если любите порядок! Однако обязательно следите, чтобы все дополнительные файлы в `hudanimations_manifest.txt` стояли выше `hudanimations_tf`, иначе они не перезапишут стандартные анимации TF2.

Если вы всё сделали правильно, ваши анимации будут работать, а игра будет автоматически обновлять все будущие анимации за вас. Конечно, если ваши собственные анимации будут обновлены, вам придётся обновлять их вручную, однако такие распространённые изменения, как анимации здоровья и боеприпасов, обновляются крайне редко.
