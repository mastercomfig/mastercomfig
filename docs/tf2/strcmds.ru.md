# Строковые команды

Строковые команды, также известные как strcmds или noncmds, это строки, которые передаются по сети для выполнения, а не обрабатываются локальной командной системой.

## Строковые команды клиента

Этот процесс происходит, когда команда не найдена в клиенте, или когда команда `cmd` используется для прямой пересылки команды на сервер. Вы также можете запустить это для ботов, используя `bot_command`.

Существует несколько типов строковых команд клиента:

* Команды движка клиента: это специальные команды, которые уже зарегистрированы на клиенте и сервере как консольные команды, но обрабатываются через строковую пересылку. Все они перечислены в списке cvarlist.
* Диспетчерские команды клиента: это консольные команды, зарегистрированные только на сервере (с флагом `GAMEDLL`), но разрешённые для выполнения клиентом. Они также перечислены в cvarlist.
* Клиентские команды: все остальные команды, которые обрабатываются вручную обработчиками на основе строковой команды и её аргументов. Они не перечислены в cvarlist.

## Список клиентских строковых команд

### Команды внутриигрового меню

* `closedwelcomemenu`: управляет тем, какое меню отображается при подключении к серверу (меню выбора команды или класса, в зависимости от авто-выбора команды). Полезна, чтобы исправить ситуацию, когда вы застреваете в наблюдателях после закрытия MOTD.
* `team_ui_setup`: открывает меню выбора команды.
* `autoteam`: автоматически присоединяет к команде.
* `menuopen`: открывает меню выбора класса.
* `menuclosed`: закрывает меню выбора класса.
* `arena_changeclass`: меняет класс в режиме «Арена».
* `jointeam`: указывает команду для смены, с ограничением не чаще раза в 2 секунды.
* `joinclass`: указывает класс для смены, с ограничением не чаще раза в 0.5 секунды.
* `resetclass`: совершает самоубийство и сбрасывает класс игрока в режиме «Хайлендер».
* `show_motd`: показывает MOTD (сообщение дня).
* `show_htmlpage`: показывает указанный URL-адрес как MOTD.
* `closed_htmlpage`: уведомляет о закрытии MOTD.
* `showroundinfo`: показывает информационную панель раунда.
* `voicemenu`: воспроизводит голосовую команду по индексу меню и пункта, например: `voicemenu 1 2`.
* `tournament_readystate`: устанавливает статус готовности команды.
* `tournament_teamname`: устанавливает название команды.
* `tournament_player_readystate`: устанавливает ваш собственный статус готовности.
* `done_viewing_loot`: завершает просмотр добычи MvM
* `ignoremsg`: управляет игнорированием чат-сообщений. Переключается между: не игнорировать, игнорировать всех и игнорировать только команду.
* `Vote`: внутренняя команда для голосования.
* `next_map_vote`: команда для выбора карты в Казуальном режиме (варианты: 0, 1 или 2).

### Действия в игре

* `weapon_taunt`: выполняет насмешку.
* `taunt`: то же, что и `weapon_taunt`.
* `stop_taunt`: прерывает длинную насмешку.
* `build`: строит постройку или ставит сапёр.
* `destroy`: уничтожает постройку.
* `eureka_teleport`: для Eureka Effect телепортирует домой или, если указано, в конкретное место: 0 (домой) или 1 (выход телепорта).
* `extendfreeze`: продлевает время смерти на 2 секунды.
* `pda_click`: воспроизводит анимацию нажатия на КПК.
* `boo`: в виде призрака произносит бу.
* `td_buyback`: выкупает себя в MvM.
* `loot_response`: воспроизводит голосовую реплику при получении добычи в конце игры MvM. Аргументы: `common`, `rare`, `ultra_rare` .
* `coach_command`: во время наставничества обрабатывает инструкции (атаковать, защищать, смотреть, идти).
* `vehicleRole`: переключает индекс роли в транспортном средстве.

### Для разработчиков

* `killtarget`: уничтожает сущность по имени/классу или с помощью пикера. Работает только с `developer 1` и `sv_cheats 1` при выполнении от имени хоста сервера.
* `addcond`: добавляет игроку эффект [по его ID](https://wiki.teamfortress.com/wiki/Cheats#addcond).
* `removecond`: удаляет эффект у игрока по ID.
* `mp_playgesture`: воспроизводит жест по имени (требуется `sv_cheats 1`).
* `mp_playanimation`: воспроизводит анимацию по имени (требуется `sv_cheats 1`).
* `te`: создаёт тестовую временную сущность (требуется `sv_cheats 1`).
* `demorestart`: запрашивает у сервера полный пакет обновления.
* `fade`: плавно затемняет экран.
* `condump_on`: включает режим Power Play; если передан дополнительный аргумент, включает для всей команды.
* `condump_off`: отключает режим Power Play; если передан дополнительный аргумент, отключает для всей команды.

### Информация

* `playerperf`: выводит историю пакетов игрока.
* `nextmap`: показывает следующую карту.
* `timeleft`: показывает оставшееся время на карте.

### Наблюдатель

* `spectate`: переключает в режим наблюдателя.
* `spec_goto`: перемещает камеру наблюдателя по координатам x y z (поворот по горизонтали и вертикали).

### Голосовой чат

* `vban`: внутренняя команда для отправки маски, сообщающей серверу, какие голосовые данные игроков игнорировать из-за статуса заглушен.
* `VModEnable`: сообщает серверу не отправлять (`0`) или отправлять (`1`) голосовые данные. Используется для передачи состояния переменной `voice_modenable`.

## Серверные строковые команды

Этот процесс запускается, когда сервер хочет, чтобы клиент выполнил команду с флагом `server_can_execute`.

Вы можете использовать команду `clientcmd` или `point_clientcommand` сущность для отправки таких команд.
